Domestic Balancing Automation

MRIO domestic transaction balancing, compilation, and change analysis.

A workflow application for producing balanced domestic transaction tables, inserting them into pre-final MRIOT workbooks, and reviewing domestic transaction changes across years or methodologies.

Application Pages

Three connected workflows

Domestic Balancing

Extracts a country domestic seed matrix from an MRIO workbook, reads reviewed controls, applies manual balancing, runs ordinary RAS, and optionally performs bounded RAS refinement.

Compile MRIOT

Fills empty domestic diagonal blocks in a pre-final MRIOT workbook using final balanced domestic tables, then produces validation checks for the compiled workbook.

Domestic Change Analysis

Compares domestic transaction cells between a base full MRIOT and uploaded final domestic tables, producing summaries, flags, charts, and heatmap outputs.

Methodology

Designed for controlled MRIO production review

The domestic balancing workflow uses the previous MRIO structure as a seed, reviewed row and column controls as targets, and proportional matrix fitting to produce a balanced table.

Growth diagnostics compare each final balanced cell with its seed value. Optional bounded RAS refinement caps the most severe non-exempt growth breach one step at a time and preserves the latest accepted balanced checkpoint if a later step reaches a dead end.

Outputs

Review-ready workbooks and summaries

  • Final balanced domestic table workbooks.
  • Full domestic balancing output workbooks with logs and diagnostics.
  • Batch ZIP outputs and consolidated final domestic tables workbooks.
  • Compiled MRIOT workbooks and compilation validation workbooks.
  • Domestic change-analysis workbooks with summary sheets, charts, and heatmaps.
